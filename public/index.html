Aktivasi Akses USB OTG di Android

⚠️ Kenapa Muncul Pesan Ini di Ponsel?

Google Chrome di Android secara sengaja memblokir akses USB & Serial jika situs dibuka melalui alamat IP lokal biasa (http://...) karena bukan koneksi aman (Secure Context).

✅ Cara Tercepat: Buka Versi HTTPS Aman

Server ArduiBlok kini telah menyediakan port HTTPS (Secure Context) otomatis di port 3443:

🔒 Buka Versi HTTPS di HP Ini *(Jika muncul peringatan sertifikat mandiri, klik "Lanjutan" lalu "Lanjutkan ke situs")*
🔧 Atau Aktifkan Flag di Google Chrome HP (1 Menit):
  1. Buka tab baru di Chrome HP, ketik: chrome://flags
  2. Cari Insecure origins treated as secure, pilih Enabled, dan masukkan URL ArduiBlok:
    http://...
  3. Cari juga Web Serial API on Android, pilih Enabled (wajib untuk Uno clone chip CH340 / CP2102).
  4. Klik tombol biru Relaunch di kanan bawah Chrome.
📱 Pengaturan Ponsel Xiaomi / Redmi (MIUI):
  • Pastikan lampu LED ON pada board Arduino menyala saat disambung kabel OTG.
  • Jika tidak menyala, buka Setelan (Settings) HP > Setelan Tambahan > OTG, lalu aktifkan saklar OTG.
